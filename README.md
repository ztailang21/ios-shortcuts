## ✨ 核心特性

- **⚡ 收到短信全自动上桌面**：基于 iOS 个人自动化「信息」触发器，收到含「取件」短信后台静默立即运行。
- **🛡️ 防误触发 & 空值守卫**：内置纯取件码正则 + 空值判断，自动跳过「已取件成功」「已签收」「验证码」「派送中」以及 11 位手机号，不写脏数据。
- **📋 标题直显 + 原短信备查**：提醒事项主标题直接显示醒目取件码（如 `12-3-4567`），完整原始短信保存在下方备注中（驿站地址、快递员电话随时点开可拨号）。
- **✅ 桌面一键核销**：配合系统原生「提醒事项」小组件，取完件在主屏幕轻点圆圈即刻完成消失，列表永不堆积。
- **📱 兼顾微信 / 支付宝通知**：手动点运行（无短信传入时）自动读取剪贴板，微信或支付宝里的取件通知复制一下也能一键入库。
- **🔒 绝对隐私安全**：全程离线在本地设备运行，无任何网络请求，绝不上传短信内容。

## 🚀 一键导入与 30 秒配置

### 第 1 步：在「提醒事项」创建列表
打开 iPhone 自带 **提醒事项** → 点击 **添加列表** → 命名为 **`待取快递`**。

### 第 2 步：一键导入快捷指令
用 iPhone 自带 **Safari 浏览器** 打开下方链接，点击「添加快捷指令」：

- **主程序「提取取件码」（必装）**：https://www.icloud.com/shortcuts/936519dc28514b698efe51b9369ec929
- *(参考)* **短信自动触发器「短信自动存取件码」**：https://www.icloud.com/shortcuts/bd4f7f46bafb4c86841d9cccad4690d8

> 💡 导入「提取取件码」后，建议点开编辑检查倒数第二步 `将 合并后的文本 添加到 待取快递`，确认列表已正确选中你刚建好的 **`待取快递`**。

### 第 3 步：配置短信自动触发
打开 **快捷指令** → **自动化** → 新建个人自动化 → 选择 **信息**：
1. 筛选条件设为 **信息包含 `取件`**；
2. 勾选 **立即运行**（关闭「运行前确认」）；
3. 添加操作 **运行快捷指令** → 选择 **`提取取件码`** → 展开并将「输入」设为 **`信息`**（收到的短信）。

### 第 4 步：添加桌面小组件（关键步骤！）
1. 主屏幕长按空白处 → 左上角 **编辑 → 添加小组件 → 提醒事项**（推荐小号或中号）；
2. **长按刚添加的提醒事项小组件 → 点「编辑『提醒事项』」→ 将「列表」从默认的 `提醒` 改为 `待取快递`**！

## 🔍 开源正则表达式（透明可审计）

本指令使用的核心 ICU 正则如下（不区分大小写，支持三段式如 `12-3-4567` / `A-2-108`、两段式如 `5-1028` 及关键词锚定的 4–8 位取件码）：

```regex
(?<![0-9A-Za-z\-])(?:[A-Za-z]-\d{1,3}-\d{1,5}|\d{1,3}-\d{1,3}-\d{1,5}|\d{1,2}-\d{3,5})(?![0-9A-Za-z\-])|(?:(?<=取件码)|(?<=取件码：)|(?<=取件码:)|(?<=取件码 )|(?<=取件码: )|(?<=提货码)|(?<=提货码：)|(?<=提货码 )|(?<=取货码)|(?<=取货码：)|(?<=凭码)|(?<=凭))[0-9A-Za-z]{4,8}(?![0-9A-Za-z\-])
```
