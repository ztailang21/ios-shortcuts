## 一、📦 取件码自动提取与桌面直显

### ✨ 核心特性

- **⚡ 三关键词全覆盖，不漏收快递短信**：iOS 短信自动化单条规则仅支持 1 个关键词，通过同时配置 **`取件` / `驿站` / `包裹`** 3 条触发器，全面覆盖菜鸟、中通、顺丰、京东、丰巢及各类社区驿站短信。
- **🔁 内置自动查重守卫（防重复写入）**：写入前自动检索「提醒事项」中是否存在**同名且未完成**的取件码记录；即使同一条短信同时命中多个关键词（如既含「驿站」又含「包裹」），也只会写入 **1 条**、弹窗 **1 次**，绝不重复堆积。
- **🛡️ 防误触发 & 空值守卫**：内置纯取件码正则 + 空值判断，自动跳过「已取件成功」「已签收」「验证码」「派送中」以及手机号/尾号，不写脏数据。
- **📋 标题直显 + 原短信备查**：提醒事项主标题直接显示醒目取件码（如 `39-5-9817`），完整原始短信保存在下方备注中（驿站地址、快递员电话随时点开可拨号）。
- **✅ 桌面一键核销**：配合系统原生「提醒事项」小组件，取完件在主屏幕轻点圆圈即刻完成消失，列表永不堆积。
- **📱 兼顾微信 / 支付宝通知**：手动点运行（无短信传入时）自动读取剪贴板，微信或支付宝里的取件通知复制一下也能一键入库。

### 🚀 30 秒配置步骤

#### 第 1 步：在「提醒事项」创建列表
打开 iPhone 自带 **提醒事项** → 点击 **添加列表** → 命名为 **`待取快递`**。

#### 第 2 步：导入「提取取件码」
用 iPhone 自带 **Safari 浏览器** 打开 [提取取件码](https://www.icloud.com/shortcuts/1c7790be611d43418c2065e0935d9b7a)，点击「添加快捷指令」。

> 💡 导入后建议点开编辑检查倒数第二步 `将 合并后的文本 添加到 待取快递（不提醒）`，确认列表已正确选中你刚建好的 **`待取快递`**。

#### 第 3 步：配置 3 条短信自动触发（覆盖 `取件` / `驿站` / `包裹`）
- **方式 A（快捷导入，推荐 iOS 27+）**：依次用 Safari 导入上方 3 条触发器（[取件](https://www.icloud.com/shortcuts/bd4f7f46bafb4c86841d9cccad4690d8) / [驿站](https://www.icloud.com/shortcuts/efb8c6f12e1c47d7ab8757c5dc2ac6df) / [包裹](https://www.icloud.com/shortcuts/a427376b46f645e4823b76f59567ae49)），随后在「快捷指令 → 自动化」中将 3 条开关全部打开，并确认已开启 **立即运行**（关闭「运行前确认」）。
- **方式 B（手动新建，通用各版本 iOS）**：打开 **快捷指令** → **自动化** → 新建个人自动化 → 选择 **信息**：
  1. 筛选条件设为 **信息包含 `取件`**（再分别复制/新建两条，关键词改为 **`驿站`** 和 **`包裹`**）；
  2. 勾选 **立即运行**（关闭「运行前确认」）；
  3. 添加操作 **运行快捷指令** → 选择 **`提取取件码`** → 展开并将「输入」设为 **`信息`**（收到的短信）。

#### 第 4 步：添加桌面小组件（关键步骤！）
1. 主屏幕长按空白处 → 左上角 **编辑 → 添加小组件 → 提醒事项**（推荐小号或中号）；
2. **长按刚添加的提醒事项小组件 → 点「编辑『提醒事项』」→ 将「列表」从默认的 `提醒` 改为 `待取快递`**！

## 二、🪪 取件身份码一键直达（多合一菜单版）

### ✨ 功能说明

用 Safari 打开 [取件身份码](https://www.icloud.com/shortcuts/27120f897d1c4b7ea989f99f7c797878) 添加后，点击即弹出菜单二选一，跳过 App 首页和层层入口，**直接展示条形码页**：

- **📦 菜鸟身份码（淘宝）**：直达淘宝内菜鸟身份码页面（需已安装并登录淘宝）
- **📮 驿收发身份码（顺丰/京东）**：直达支付宝「驿收发」小程序身份码页面（需已安装支付宝并在首次进入驿收发小程序时完成一次手机号授权）

### ⚡ 推荐一键触发方式（任选其一）

- **轻点背面（最顺手）**：`设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下/三下` → 绑定 **`取件身份码`**，走到驿站扫码机前敲两下手机背面即可出码。
- **主屏幕图标 / 锁屏小组件 / 控制中心 / 操作按钮**：在快捷指令中长按 `取件身份码` → **共享 → 添加到主屏幕**，或在锁屏/控制中心直接绑定。

## 🔍 开源正则表达式（透明可审计）

「提取取件码」使用的核心 ICU 正则如下（不区分大小写，支持三段式如 `39-5-9817` / `A-2-108`、两段式如 `5-1028` 及关键词锚定的 4–8 位取件码）：

```regex
(?<![0-9A-Za-z\-])(?:[A-Za-z]-\d{1,3}-\d{1,5}|\d{1,3}-\d{1,3}-\d{1,5}|\d{1,2}-\d{3,5})(?![0-9A-Za-z\-])|(?:(?<=取件码)|(?<=取件码：)|(?<=取件码:)|(?<=取件码 )|(?<=取件码: )|(?<=提货码)|(?<=提货码：)|(?<=提货码 )|(?<=取货码)|(?<=取货码：)|(?<=凭码)|(?<=凭))[0-9A-Za-z]{4,8}(?![0-9A-Za-z\-])
```
